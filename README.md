I am a beginner programmer so please point out any mistakes or suggestions :) . Read README for instructions of use
--------------------------------------------------------------------------------------------------------------------

HOW TO USE THE MACRO:
1. Equip the "Requiem" rod.
2. Go to Lost jungle and fish near the small river.
3. Equip the "Tropical Toucan" companion.
4. Press F8 to start the macro and F7 to stop it.

P.S. Stand in a spot where you can cast the rod always in the water; Preferably dont use shiftlock -> it moves your camera
