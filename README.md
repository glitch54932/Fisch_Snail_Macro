# Fisch Snail Macro

A small beginner passion-project macro for the Roblox game **Fisch** that helps automate snail farming.
--------------------------------------------------------------------------------------------------------------------

## What it does

- Automates part of the snail farming process.
- Designed for use with the **Requiem** rod.
- Designed for **Lost Jungle**, near the small river.
- Uses the **Tropical Toucan** companion.
- Press **F8** to start.
- Press **F7** to stop.

## In-game requirements

- Requiem rod
- Tropical Toucan companion
- Access to Lost Jungle

## How to use

1. Equip the **Requiem** rod.
2. Go to **Lost Jungle** and fish near the small river.
3. Equip the **Tropical Toucan** companion.
4. Stand in a spot where your rod will always cast into the water.
5. Avoid shiftlock if possible — it moves your camera and can mess up the macro.
6. Press **F8** or "Start" to start the macro.
7. Press **F7** or "Stop" to stop the macro.
